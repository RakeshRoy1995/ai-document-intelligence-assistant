# ai-document-intelligence-assistant
I built a tool that lets you ask questions about your own documents and get clear answers, with the exact page each answer came from.

Anyone who has searched through a long report, contract or manual knows the problem. Finding one fact can take far too long. This tool does the searching for you.

Here is how it works, in plain terms:

1. Reading: you upload a PDF. The tool reads the text, headings, tables and images, and keeps them in the right order.

2. Organising: it breaks the document into small sections, grouped by their headings, so each piece has its topic and page number attached.

3. Finding: when you ask a question, the tool looks for the sections most likely to contain the answer. It also rewords your question a few ways, so it doesn't miss information that's written in different words.

4. Answering: an AI model reads those sections and writes an answer. Every statement points back to its source, so you can check it yourself.

5. Remembering: when someone asks a question that has already been answered, the saved answer is shown straight away. You can give each answer a thumbs up or down, and the tool learns from that.

Everything runs on my own computer, so the documents never leave it.

The biggest lesson: a tool like this is only useful if you can trust its answers. Checking the sources, and making sure it doesn't mix up similar details such as "2023" and "2021", mattered far more than the technology itself.
